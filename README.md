## Description

Maven parent poms, Maven arquetypes, Maven plugins and basic support libraries for the arquetypes.

Supported Languages:
	
* C
* C++
* Java
* Python
* Typescript
	

## Requirements

* C			c2x
* C++		c++20	
* Java 		21
* Maven 	3.9.x
* Python 	3.14.x

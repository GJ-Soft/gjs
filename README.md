## Gjs project

Project Gjs

## Description

Maven parent poms, Maven arquetypes, Maven plugins and basic support libraries for the arquetypes.

Supported Languages:
	
	C
	C++
	Java
	Python
	Typescript
	

## Requirements

* Maven 3.9.x


## Configuration

* Settings.xml:

		<pluginGroups>
			<pluginGroup>org.gjs.maven.plugins</pluginGroup>
			<pluginGroup>org.sonarsource.scanner.maven</pluginGroup>
		</pluginGroups>


      
## Installation
    
    mvn clean install

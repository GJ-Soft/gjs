## GZ maven extension 

 Project GZ Maven Extension 
 
## Description

Project plugin in java language.

Define the gz packaging for maven projects 


## Requirements

* Maven 3.9.x


## Use

<packaging>gz</packaging>

<build>
	<extensions>
		<extension>
			<groupId>org.gjsoft.maven.extensions</groupId>
			<artifactId>gz-maven-extension</artifactId>
			<version>1.0.0-RC.2</version>
		</extension>
	</extensions>
</build>

    mvn clean install
